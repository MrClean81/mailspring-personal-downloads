# Mailspring Personal downloads

Download the personal Windows edition of Mailspring with a classic email interface.

**[Download page](https://mailspring-personal-download.cuddlyboot3.chatgpt.site)** · **[Releases and files](https://github.com/MrClean81/mailspring-personal-downloads/releases/latest)**

Download the `.exe` installer from the latest release, run it on a Windows x64 PC, and connect your own email account. A GitHub account is not required to download.

This is an independently modified build based on [Mailspring](https://github.com/Foundry376/Mailspring), not Microsoft Outlook or an official Mailspring release. The installer is unsigned, and Windows may warn or block it. It uses the normal Mailspring installation and profile locations.

Public releases are installed manually. Automatic updates require separately configured access to the private update feed. Downloading and using the app does not require access to that feed.

Each release includes matching source code, license information, and SHA-256 checksums. The application is licensed under GPL v3; retain upstream and dependency notices.
